First public preview of open-ax12, an open-source replacement for the stock app on the RadioMaster AX12.

**Status: early alpha.** Built against the RadioMaster SDK and tested briefly on one AX12 (live values, stick display, connection). Most configuration screens have only been exercised against the built-in simulator. Do not rely on it for flight-critical setup yet: check every model on the ground with the receiver connected and the propeller removed.

No APK is attached to this release. Build it yourself (see the README) or take the dev APK from the latest successful run of the Android workflow on `master`.
